# Rishabh Jha - Portfolio

Clean & minimal personal portfolio built with **React + Tailwind CSS + Framer Motion**.

## Features

- Responsive single-page design
- Smooth animations with Framer Motion
- Sections: Hero, About, Projects, Skills, Experience & Education, Certificates, Contact
- Live project links included (Campus Placement System)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deploy on Vercel (Recommended)

1. Push this folder to a new GitHub repository
2. Go to [vercel.com](https://vercel.com) → Sign in with GitHub
3. Click **Add New Project** → Import your repo
4. Click **Deploy** (no extra settings needed)

Your site will be live in under 1 minute.

## Project Structure

```
src/
  App.jsx       → Main portfolio component
  index.css     → Tailwind styles
  main.jsx      → Entry point
```
